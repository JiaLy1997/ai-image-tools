# 图片工具箱

免费、好用的在线图片处理工具，支持手机和电脑端使用。

## 功能

- **图片压缩** — 可调节质量，保持清晰度的同时减小文件体积
- **格式转换** — JPG / PNG / WebP / AVIF 互转
- **图片裁剪** — 支持 1:1、4:3、16:9 等常用比例
- **添加水印** — 自定义文字、位置、透明度、字号
- **调整尺寸** — 自定义宽高，支持等比缩放
- **图片旋转** — 任意角度旋转，支持水平/垂直翻转
- **图片拼接** — 多张图片合并为一张
- **滤镜调色** — 亮度、对比度、饱和度、模糊等滤镜

## 技术栈

- Next.js 16 + React 19
- Tailwind CSS 4
- sharp（服务端图片处理）
- Canvas API（客户端图片处理）
- PWA 支持

## 开发

```bash
npm install
npm run dev
```

访问 http://localhost:3000

## 部署

```bash
npm run build
npm start
```
